# Security policy

Report a suspected vulnerability privately to the project maintainers. Do not
open a public issue for credential exposure, authorization bypass, webhook
verification defects, attachment handling flaws, or tenant-isolation failures.

Never include Resend API keys, webhook secrets, raw private email, or private
attachments in a report. Maintainers will acknowledge the report, assess
impact, coordinate a fix, and publish a disclosure after affected users can
upgrade.
