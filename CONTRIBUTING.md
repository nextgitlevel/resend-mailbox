# Contributing

Read `AGENTS.md`, `docs/QUALITY_GATES.md`, and the active tracker before
opening a change. Follow red → green → refactor, keep changes scoped, record
verification evidence, use a conventional commit, and push the verified commit
to its upstream.

Do not submit credentials, private emails, attachments, production data, or
generated environment files. Security issues belong in `SECURITY.md`, not in a
public issue.
